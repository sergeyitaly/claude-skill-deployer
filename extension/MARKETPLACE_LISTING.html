Claude Skills Manager

Detect your project stack, deploy the right AI agent skills, and control Claude credit spend — from one VS Code sidebar.

Why install this?

  • Stop guessing which skills to enable — auto-detect from your repo (Terraform, Azure, GitLab CI, ADX, and more).
  • See where credits go — Cost Intelligence Dashboard with per-skill attribution across Claude and Cursor.
  • Set a daily budget — warn at 80%, auto-disable expensive skills, optional emergency cutoff.
  • One library, four agents — Claude Code, Cursor, Kiro, and GitHub Copilot from the same manifest.

Quick start (2 minutes)

  1. Open a workspace folder.
  2. Activity bar → Claude Skills → Install Skill Library to ~/.claude/skills.
  3. Run Install Relevant Skills for Workspace (or accept the onboarding tour).
  4. Optional: Enable Cost Control Hooks and open Cost Intelligence Dashboard.

Feature toggles

Disable anything you do not need — Command Palette → Claude Skills: Manage Feature Toggles

  • Budget controls, branch profiles, multi-agent sync
  • Attribution collector, auto-optimizer, emergency cutoff
  • Community benchmarks (opt-in), PR cost estimates (optional)
